About Event Management Intelligence

This web application is an advanced interactive Event Management and Operations System tailored for technical campuses, workshops, hackathons, and interactive games. Built with a responsive modular dashboard, it supports custom dynamic event scheduling, minigames (Tic-Tac-Toe, Trivia, Lucky Wheel), and role-based operator tracking.

Version: 2.5.0-PRO Engine: Tailwind & Vanilla JS
